## 🚀 Key Features

### 1. 📻 Live Radio Station (88.5 FM)
- **Persistent Bottom Player Bar**: Allows listeners to tune in and listen to Enduata FM while seamlessly browsing news, past broadcasts, and interviews.
- **Live Equalizer Visualizer**: Dynamic animated sound bars indicating active transmission.
- **Quality Selector**: 64 kbps (Data Saver), 128 kbps (Standard), 320 kbps (HD).
- **Custom Stream Link Config**: Switch between the default stream or enter an Icecast / Shoutcast / Zeno.fm direct stream URL in real time.
- **Live Song Request & Shoutout Form**: Listeners can send shoutouts directly to the on-air presenters.

## 💻 How to View & Run
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari) or serve it with any web server:
```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
